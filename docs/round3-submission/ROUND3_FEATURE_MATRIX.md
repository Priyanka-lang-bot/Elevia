# ELEVIA: Implemented features and limitations

Status as of 23 November 2026 (branch `six-month-demo`). Status values:

- **Verified**: implemented and exercised by tests or a browser run that actually executed (see section 17 of the technical documentation).
- **Implemented, not fully verified**: the code exists and works in tests, but not against the real external service or the live site.
- **Partial**: some of the intended scope exists.
- **Planned**: not implemented. Listed so the scope is clear.

Real, simulated and sample are kept apart:
- **Real:** every decision is made by deterministic rules in the code.
- **Synthetic:** the demo's six-month history uses simulated *answers*, run through the real workflow on a simulated calendar.
- **Simulated:** the optional AI wording has only been tested against simulated model responses.
